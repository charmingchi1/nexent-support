## 二、答复模板（按定性选用，交用户过目后转发）

### 模板A · 使用问题
```
您好，您反馈的现象是 <操作/理解偏差点> 导致的，不是系统故障。
正确操作：<步骤 1/2/3>
如按上述操作仍有问题，请回传现象截图（脱敏），我们继续跟进。
```

### 模板B · 配置问题
```
您好，该现象为 <配置项> 配置不当所致，与系统功能无关。
定位依据：<日志关键行/现象特征>
请按以下步骤调整：
<命令/配置片段>
修改后验证方式：<验证命令>。预期 <预期结果>。
```

### 模板C · 真实 bug（短期规避）
```
您好，经排查确认这是一个系统缺陷：<一句话现象与根因>。
短期规避方案：<可立即执行的操作，含命令/配置>，执行后 <预期效果>。
该问题已在问题跟踪表中登记（编号 <记录链接>），计划在 <预期修改版本> 修复，
修复后我们会通知您升级验证。给您带来不便深表歉意。
```

### 模板D · 排查超时升级预告(v2 收窄)

```
您好，您反馈的问题我们已收到并开始排查：<现象复述>。
为确保结论准确，需升级至 <责任模块> 模块负责人进一步定位，
预计 <时间> 内给您初步结论。期间如现象有变化请随时同步。
```

### 模板E · 环境事件(定性规范 v2 新增)
```
您好，您反馈的现象经核实为 <环境原因：资源不足/网络策略/平台升级波动> 所致，
```

### 模板F · 模型/能力限制(定性规范 v2 新增)
```

我们已将此限制记录在「已知限制清单」，后续版本如有改进会同步告知您。
```

### 模板G · 新需求/能力边界(定性规范 v2 新增)
```
您好，您提到的 <能力> 目前版本暂不支持，理解您的诉求。
```
