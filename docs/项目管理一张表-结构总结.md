```

│  1 需求池    │◄───────────►│  2 版本开发计划    │

        6 与其他表无link，暂未启用◄────────│  (15条)      │
                                          └─────────────┘
```

核心协作链路：

1. **需求 → 开发计划**：需求池中 RAT 评审接纳的需求（43 条已建立连接），排入「2 版本开发计划」，填写工作量（人月）、计划交付版本、进展。
2. **开发计划 → 发布版本**：计划交付的内容通过「合入发布版本」挂到具体版本（55 条已关联）。
3. **问题 → 发布版本**：问题跟踪中每个问题通过「发现版本」标注在哪 个版本引入，「计划修复版本」标注计划在哪个版本修复，发布版本表反向统计「发现问题数 / 计划修复数」（如 v2.5.0 计划修复数 2 / 发现问题数 56；v2.5.1 补丁版计划修复 93）。
4. **问题 → 需求**：「解决方式=转需求」的问题可转入需求池（该 link 字段已建但尚未使用）。
